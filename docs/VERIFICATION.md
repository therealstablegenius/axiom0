## What v0.7 verifies, by concern

| Concern (from the v0.6 external review) | How it is verified |
|---|---|
| Ledger rollback / coherent rewrite on the host | `test_v07_anchor.py` performs the attack: an event is changed and the whole chain re-hashed and re-signed with the real key. Local verification passes; the published anchor detects it. Truncation (rollback) and forged/foreign receipts are also tested. The stand-alone verifier (`tools/axiom0_audit_verify.py`) catches a one-field change in an exported event. |
| Reviewer identity was a self-asserted label | `test_v07_reviewers.py`: the API takes the reviewer's name from their personal key (never from the request), keys are stored only as hashes, revocation takes effect, and the shared key is recorded as `shared_key` and can be disabled. |
| DNS rebinding in the fetcher | `test_v07_dns_pinning.py`: a resolver that answers public then private is used; the request goes to the first, validated address with only one lookup. A real TLS server proves the certificate is still checked against the true hostname when connecting to a pinned IP. |
| Naive spike statistics | `test_v07_spikes.py`: tail probabilities against closed forms; Benjamini–Hochberg against a known example; 150 unchanged area/category pairs produce several v1 false alarms and zero v2 flags, while a genuine spike among them is still found; recurring seasonal peaks are not flagged. |
| Untested Windows path | CI job `windows-installer` runs the real installer on Windows, checks the secrets file is owner-only data, starts the server, checks health and authentication, runs the CLI cycle including backup/restore and independent verification, and proves a v0.6 secrets script is converted **without being executed**. |
| LLM grounding never tested with a model | `tools/eval_grounding.py` measures citation correctness, stated facts, refusal on unanswerable questions (including a keyword trap) and lexical support against a real Ollama model. `test_v07_eval_tool.py` proves the tool catches an invented answer. **Real-model results must be produced on the target hardware** (see below). |
| Doc drift | This page's counts are generated; CI fails when they are stale. |
| No schema migration story | `test_v07_migrations.py` upgrades a real v0.6 database, preserves data, records each migration in the signed ledger, and refuses to run older code against newer data. |
| Substring forbidden-action check | `test_v07_misc.py`: rephrased requests (tickets, grant money, backdating records, watch lists) are blocked; ordinary follow-up wording passes. Still a guardrail, not a control. |
| Excerpts looking like answers | `ask` findings are labelled `source_excerpt` with a `how_to_read` statement; tested in `test_v07_misc.py`. |
| 3·6·9 material in the municipal API | Off by default (404 on its routes, hidden in the dashboard, CLI refuses); tested in `test_v07_misc.py` and `test_v07_cli_backup.py`. |

## Manual / environment checks performed for v0.7

- Raspberry Pi 5 installer: full install, re-install with a different profile, ingest,
  `ask --llm`, doctor, speed test and uninstall on Linux with stand-ins for Ollama and
  systemd (v0.6.1), plus a dry run with daily anchoring enabled (v0.7).
- `Start-AXIOM0.ps1` run under PowerShell 7.4: serves, accepts the right key (200),
  rejects a wrong key (401), refuses an injection-shaped secrets file. Both Windows
  scripts parse without errors.
- Anchor publishing script: receipts committed and pushed to a git remote; after a
  simulated rollback it raises an alert, exits with code 3 and issues no new anchor.

## Not yet verified

- **Real model grounding numbers.** Run on the Pi (or the target PC):
  `python3 tools/eval_grounding.py --out eval-results` and keep the report here.
- **Raspberry Pi 5 hardware**: thermals, throttling and real tokens/second.
- **Windows on a City workstation** (CI uses a clean GitHub runner, not a managed City image
  with its own policies, antivirus and proxy).
- Penetration testing, WCAG audit of the dashboard, legal review, and SSO/OIDC integration.
- Spike detector calibration against real 311 history (v2 is statistically sounder, not validated
  against ground truth).
